# Ask Question

When you need input from the user:

## Binary choice (this or that)

Present exactly two options and ask the user to answer **A** or **B**.

## More than two options

1. Pick the **top 2** best options and label them **A** and **B**.
2. Offer **C** as free-form: the user provides their own answer in text.

Do not proceed until the user has answered.
