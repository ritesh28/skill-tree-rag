# Read PDF

Use pymupdf via `scripts/read-pdf.py` to extract text from a PDF and print it to stdout for the agent.

1. Ask the user for the path to the PDF.
2. Run the script and use the printed text.

```bash
uv run --python .venv/bin/python skills/create-and-modify-pdf/scripts/read-pdf.py <path-to.pdf>
```
