# Create PDF

1. Ask the user for the text to write into the PDF.
2. Infer a PDF filename from that text (short slug + `.pdf`).
3. Ask the user where to create the file (output directory).
4. Ask whether they want **Node (PDFKit)** or **Python (pymupdf)**:
   - Treat this as a binary choice (A = Node / `scripts/create-pdf.ts`, B = Python / `scripts/create-pdf.py`). Prefer the ask-question skill pattern when available.
5. Run the chosen script with the output directory and text.

## Scripts

- Node: `scripts/create-pdf.ts`
- Python (via repo-root `.venv` / `uv`): `scripts/create-pdf.py`

Both write a PDF with a left-side footer: `generated by AI`.

## Example invocations

```bash
npx tsx skills/create-and-modify-pdf/scripts/create-pdf.ts <outdir> <text...>
uv run --python .venv/bin/python skills/create-and-modify-pdf/scripts/create-pdf.py <outdir> <text...>
```
